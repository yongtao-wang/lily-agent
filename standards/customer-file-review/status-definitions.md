# Status Definitions

Use these statuses consistently in review reports.

| Status | Meaning | Use When |
|---|---|---|
| `符合` | Meets the standard | Required material is present and evidence suggests it is usable. |
| `缺失` | Missing or clearly below requirement | A required item is absent, too few files are provided, a required field is empty, or evidence clearly conflicts with the standard. |
| `需确认` | Needs confirmation | Evidence is incomplete, ambiguous, unreadable, inaccessible, or dependent on business/project type. |
| `可优化` | Present but improvable | Material exists but can be stronger, clearer, more complete, or better organized. |

## Evidence Requirements

- Every status must cite evidence: a file path, folder path, spreadsheet field, or short quote from the customer material.
- Use `需确认` when the agent cannot inspect a file's content or dimensions.
- Use `缺失` only when the reviewed package provides enough context to determine the required item is absent or inadequate.
- Optional/recommended items should usually be `可优化` or `需确认`, not `缺失`, unless the user asked for a strict optional-item audit.
