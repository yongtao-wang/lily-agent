# 01 Preparation Rules / 资料整理前必读

Source PDF: `../source-pdfs/01-资料整理前必读.pdf`

## Core Principle

Reduce customer burden. Customers may submit drafts in the language they are most comfortable using, including mixed-language drafts, original images, and rough product names. The service team handles target-language adaptation, SEO optimization, keyword research, image renaming, compression, alt text, and image processing.

## Required Text Rules

- Customer-provided content in any language is acceptable.
- Customer-provided professional terms are valuable and should be preserved for confirmation.
- Do not mark single-language copy or source-language copy as non-compliant.

## Required Image Rules

- Images should be high resolution; width should not be below `900px` where dimensions can be checked.
- Images should be clear, without watermarks, not screenshots, and not scraped from the web.
- Product cutout versions are useful if available, but the customer is not required to do cutout work.
- Each image folder should include a simple image description table with filename and a short description in any language.
- Customers do not need SEO-standard filenames in any specific language; the service team will rename images.

## Required Keyword Inputs

Customer should provide, when available:

- Target market/countries.
- At least 3 competitor website links.
- Existing keyword list if they already have one.

Keyword research and final keyword planning are handled by the service team.

## Parallel Work Guidance

- Do not require modules to be completed sequentially.
- Homepage materials can start design early.
- Brand assets should be confirmed early because they affect the visual style.
- Product detail work should start early because product rows and images usually take the most time.
- Product categories and product details can be prepared together.
- About us, solutions, and cases can be prepared by different people in parallel.

## Image Folder Placement Guide

| Module | Expected Images |
|---|---|
| 04 Homepage Hero | High-resolution hero background candidates. |
| 04 Homepage Social Proof | Customer logos, certificates, media proof. |
| 04 Homepage Why Choose Us | R&D, factory, process, data proof, certification or award images. |
| 05 Product Category | One category header image per category. |
| 06 Product Detail | At least 3 product images per product, organized by category/product folders. |
| 07 About Us | Factory, workshop, team, certificates. |
| 08 Solutions | Solution representative images, or product images if no dedicated solution images exist. |
| 09 Case Library | Site/product photos, 2-5 per case, one folder per case. |
| 03 Brand Assets | Logo, QR codes, certificates, catalogs. |

## Common Review Warnings

- If the image width is below `900px`, mark it `缺失` or `可优化` depending on whether a usable alternative exists.
- If the image content cannot be inspected, mark quality as `需确认`.
- If image descriptions are missing, mark the module `可优化` unless descriptions are essential to identify required items.
