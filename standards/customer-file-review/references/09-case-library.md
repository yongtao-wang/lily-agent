# 09 Case Library / 案例库

Source PDF: `../source-pdfs/09-案例库·填写规范.pdf`

## Scope

Each case becomes an independent SEO content asset. Homepage cases are selected from the case library.

## Required Fields

Each case row should include:

| Field | Requirement |
|---|---|
| Case ID | Example: `Case 01`. |
| Case title | Any customer-preferred language. |
| Customer company name | If unauthorized, use a generic name such as `A leading XX company`. |
| Customer country | Required. |
| Customer industry | Required for filtering. |
| Authorization to use customer name | `Yes` or `No`. |
| Delivered products | Should correspond to product detail page product names. |
| Customer pain point/original need | 200-400 words, specific and concrete. |
| Our solution | 200-400 words, focusing on what was done differently. |
| Delivery result/customer feedback | 100-300 words; data is preferred. |
| Image folder name | Must match the corresponding case image subfolder. |
| Homepage featured? | `Yes` or `No`. |

## Recommended Fields

| Field | Recommendation |
|---|---|
| Cooperation date | Example: `2026.3`. |
| Order size | Can be approximate, such as `Over $500K` or `50+ units`. |
| Customer testimonial | Original customer wording is valuable if available. |
| Testimonial person and title | Recommended when testimonial is used. |
| Related solutions | One or more solution names/IDs. |

## Image Placement

Place images under `09-案例库/`, one folder per case. The folder name must match the `Image folder name` field, such as `case-01-us-coffee-chain-tumblers/`.

Each case should include at least 3 images, including a cover image and site/product images.

## Review Notes

- If customer name authorization is `No`, customer-facing copy should use a generic description.
- If images are fewer than 3 for a required case, mark the image item `缺失`.
- If the case is selected for homepage but missing a cover image, mark homepage/case linkage `缺失` or `需确认` depending on evidence.
