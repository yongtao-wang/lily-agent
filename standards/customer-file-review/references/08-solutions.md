# 08 Solutions / 解决方案

Source PDF: `../source-pdfs/08-解决方案·填写规范.pdf`

## Scope

Solutions are parallel to Products in the website architecture. They organize content by buyer problem, industry, application scenario, or customer type.

## Organization Options

Choose one organization mode and keep it consistent:

| Mode | When to Use | Examples |
|---|---|---|
| By industry | Most common; products serve multiple industries. | Coffee chains, outdoor brands, hospitality, corporate gifting. |
| By application scenario | Product use cases differ strongly. | Hot beverages, cold drinks, kids/school, travel/commute. |
| By customer type | OEM, distributor, e-commerce, or end-user decisions differ. | OEM brand clients, distributors, e-commerce sellers. |

## Required Fields

Each solution row should include:

| Field | Requirement |
|---|---|
| Solution name | Any customer-preferred language. |
| Industry/scenario category | The chosen Solutions dimension. |
| Typical pain points | 100-200 words describing the customer's industry problem. |
| Solution description | 200-300 words explaining products, process, and services used to solve the problem. |
| Applicable products | Product names or model numbers, comma-separated if multiple. |
| Representative cases | 1-3 case IDs when available. |
| Key data/highlights | Concrete metrics if available. |
| Representative image | Filename matching the image folder. |

## Recommended Quantity

Start with 3-6 solution pages covering the strongest industries or scenarios. More can be added later for SEO growth.

## Image Placement

Place images under `08-解决方案/`, ideally one folder per solution. The filename should match the representative image field in the solution table.

## Review Notes

- If the customer mixes industry, application, and customer-type organization in one navigation, mark `可优化`.
- If representative cases are not available, mark `可优化` rather than `缺失`, unless the customer claimed the case exists.
- Do not mark missing slug, page title, meta, or keywords as a customer gap.
