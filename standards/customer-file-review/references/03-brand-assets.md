# 03 Brand Assets / 品牌素材

Source PDF: `../source-pdfs/03-品牌素材·填写规范.pdf`

## Required Items

| Item | Requirement | Evidence to Check |
|---|---|---|
| Color logo | Color logo, preferably transparent PNG. | File under `03-品牌素材/logo/` or equivalent. |
| White/reversed logo | White or reversed logo for dark backgrounds. | File under `03-品牌素材/logo/` or equivalent. |
| Contact methods | WhatsApp, Email, Phone. | Form fields, text file, spreadsheet, or contact document. |
| Quality certification or test report | At least 1 clear certificate/report. | File under `03-品牌素材/certificates/` or equivalent. |

Common certificate examples: ISO 9001, FDA food-contact material, LFGB, BPA-Free statement, SGS/Intertek report, BSCI/Sedex, or other industry-specific certificates.

## Recommended Items

| Item | Requirement | Evidence to Check |
|---|---|---|
| Brand color/font guidance | If the customer has visual requirements, they should document them. | Brand guideline PDF, text note, or design file. |
| Company catalog | Company-wide catalog or product-line manuals. | PDF under `catalog/` or equivalent. |
| Event photos | Trade show or activity photos for trust sections. | Files under `events/` or equivalent. |
| Awards/media | Awards, media reports, screenshots, links. | Files under `awards-media/` or equivalent. |

## Suggested Folder Structure

```text
03-品牌素材/
  logo/
  brand-guideline/
  certificates/
  catalog/
  events/
  awards-media/
```

## Review Notes

- If only one logo variant exists, mark the missing variant `缺失`.
- If certificate files are present but unreadable or cannot be opened, mark `需确认`.
- If catalog/events/awards are absent, mark `可优化`, not `缺失`, unless the user requested a strict optional-item audit.
