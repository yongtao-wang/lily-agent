# 00 Start Here / 开始这里

Source PDF: `../source-pdfs/00-开始这里·阅读指南.pdf`

## Purpose

Orient the customer to the B2B website material collection process. Customers provide product knowledge, company stories, and original assets in the language they are most comfortable using; the service team handles target-language adaptation, SEO, image processing, keyword research, and architecture planning.

## Project Type

| Type | Meaning | Review Impact |
|---|---|---|
| `A 类：重新设计` | Customer has an old website and wants rebuild/redesign/migration. | Old URLs can be used as reference, but key content, SEO, missing sections, and weak images still need updates. |
| `B 类：全新站` | Customer has no website and only raw materials. | Required modules should be completed more fully because they become the blueprint. |

If project type is not stated, mark type-dependent items as `需确认`.

## Module Priority

| Module | A 类 | B 类 | Review Notes |
|---|---:|---:|---|
| 01 Preparation rules | Required | Required | Customer should understand text/image rules and parallel workflow. |
| 02 Basic info | Required | Optional | No separate `02` standard exists in this pack; do not invent rules. |
| 03 Brand assets | Required | Required | Logo, certificates, contact details, hard assets. |
| 04 Homepage | Old URL plus missing sections | Required | Highest priority; starts homepage design. |
| 05 Product category pages | Old URLs plus add/delete/change notes | Required | Product category structure for engineering-oriented visitors. |
| 06 Product detail pages | Old URLs plus SEO rewrite list | Required | Highest workload; product rows and images should start early. |
| 07 About us | Old URL plus updated data/images | Required | Company story, factory, team, trust proof. |
| 08 Solutions | Usually fill like B type | Required | Industry/application/customer-type pages. |
| 09 Case library | Required | Required | Independent SEO content assets. |

## Architecture Principle

The site uses `Products + Solutions + Cases`:

- Products organize what the company sells.
- Solutions organize by industry, application, or customer type.
- Cases prove delivery with real examples.

Solutions can link to multiple products; cases can link to solutions and products.

## Required Review Points

- Confirm project type if available.
- Confirm which modules were submitted.
- For A-type projects, look for old website URLs where the relevant module requires them.
- For B-type projects, check whether required module forms/materials are present.

## Recommended Review Points

- Confirm target market, competitor URLs, and keyword list if provided.
- Note whether homepage and product detail materials are ready early, because they unblock design and content work.
