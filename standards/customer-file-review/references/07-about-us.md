# 07 About Us / 关于我们

Source PDF: `../source-pdfs/07-关于我们 ·填写规范.pdf`

## Scope

Customer-provided content in any language is acceptable. The service team handles target-language adaptation and SEO optimization.

## Required Items for A-Type Rebuild

| Item | Requirement | Evidence to Check |
|---|---|---|
| Old About Us URL | Link to existing About Us page. | URL field, document, or message. |
| Updated company data | Founded year, factory area, employee count, annual capacity, export countries if changed. | About form/table fields. |
| Factory site images | 5-10 high-resolution photos; old low-resolution images should be replaced. | Files under about/factory image folders. |
| Certificate scans | ISO 9001, FDA, LFGB, BPA-Free, SGS, or similar; clear and readable. | Certificate files. |

## Required Items for General Review

| Field | Requirement |
|---|---|
| Formal company full name | Official company name as it should appear in site/footer materials. |
| Founded year | Example: `Founded in 2005`. |
| Headquarters location | Customer-provided location format is acceptable; the service team can adapt it for the target site language. |
| Factory/office address | Complete address. |
| Contact email | Company-level email. |
| WhatsApp/phone | International format with country code. |
| Employee scale | Example: `50-100` or `100-500`. |
| Factory area | Example: `5000 m²`. |
| Annual capacity | Example: `500+ units/year`. |
| Company story | Sufficiently detailed company story; roughly 300 Chinese characters or equivalent detail in another language. |
| Factory/workshop photos | At least 3 high-resolution factory photos covering key scenes. |

## Recommended Items

| Item | Recommendation |
|---|---|
| Milestone timeline | Key years and events, suitable for visual timeline. |
| Company/factory video | HD video, ideally 1-3 minutes. |
| Image descriptions | Each subfolder should include a description table. |

## Review Notes

- For A-type projects, old URL and updates are required.
- If exact business metrics are sensitive, mark as `需确认` and ask for acceptable public ranges.
